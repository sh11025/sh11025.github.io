식자실 게임은 처음에 51MB를 받아야 했고, 같은 파일이 여러 곳에 있어 고쳐도 화면이 안 바뀌는 일이 생겼습니다.

이렇게 풀었어요재고, 한 벌로 합치고, 규칙으로 막기

받는 양을 재며 그림을 가볍게 하고, 공용 코드를 한곳에 모으고, 같은 실수를 막는 규칙과 자동 검사를 넣었습니다.

그래서 이렇게 됐어요가볍고 정돈된 사이트로 업로드 준비 완료

식자실 13.6MB, 폴더 576MB, 휴대폰은 전용 페이지로 자동 연결됩니다.

  • 식자실 게임 — 시간 초과 연출, 귀신 6종 움직임, 화면 겹침·단축키 정리, 끝 화면 단추

배경

왜 만들었나요

경성야록은 1930년대 신문 지면을 본뜬 미스터리 아카이브입니다. 본지, 4대 사건, 전시관 9곳, 그리고 3D 탈출 게임 '식자실'로 이루어져 있습니다.

기능이 계속 붙으면서 사이트가 무거워지고, 같은 역할의 단추와 코드가 여러 벌 생겼습니다. 저는 먼저 만들어 둔 제작본을 이어받아, 문제를 직접 찾고 클로드로 원인을 분석해 안티그래비티에 수정을 맡기고, 결과를 실제 파일과 대조해 확인하는 방식으로 6일 동안 정리했습니다.

51MB → 13.6MB식자실 게임 처음 받는 양
1.3GB → 576MB작업 폴더 용량
1.2초 → 0초첫 귀신 등장 때 멈춤
234MB업로드 묶음 (파일 2,220개)
작동 방식

어떻게 작동하나요

핵심 기능

6가지

1로딩 속도

큰 그림을 가볍게 바꾸고 화면에 보일 때만 받게 해, 페이지마다 처음 받는 양을 크게 줄였습니다.

2공용 코드 한 벌

여러 곳에 흩어진 같은 파일을 한곳에 모아, 한 번 고치면 모든 페이지에 반영됩니다.

3휴대폰 전용 페이지

휴대폰에서 사건을 누르면 전용 페이지가 열리고, 읽은 기록과 수사일지도 PC와 같게 남습니다.

4식자실 게임 정리

겹치던 화면 장치와 단축키를 정리하고, 끝 화면에서 다시 도전·본지로 나가기를 고쳤습니다.

5귀신 연출

멈춰 있던 귀신 6종을 움직이게 하고, 10분 안에 모두 나오도록 등장 시간을 맞췄습니다.

6자동 안전장치

저장할 때 한글 깨짐과 파일 형식 바뀜을 검사해, 문제가 있으면 저장을 막습니다.
