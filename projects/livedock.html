세 줄로 보는 라이브도크

불편했던 점방송이 멈췄는데 늦게 아는 것

탭을 여러 개 띄워 두고 계속 새로고침해야 했습니다.

이렇게 풀었어요화면 한구석에서 서버를 계속 지켜보는 작은 창

응답 속도를 재서 정상·지연·장애로 보여 주고, 문제가 생기면 바로 알립니다.

그래서 이렇게 됐어요실제 송출 현장에서 빠르게 대처

예전 회사 후임이 방송 중 이 프로그램 덕분에 빠르게 대처했다고 알려 왔습니다.

배경

왜 만들었나요

라이브 송출 일을 하면서 가장 무서운 건 '방송이 멈췄는데 늦게 아는 것'이었습니다. 브라우저 탭을 여러 개 띄워 두고 계속 새로고침하는 대신, 화면 한구석에서 서버 상태를 계속 지켜보는 작은 창이 있으면 좋겠다고 생각했습니다.

실제 사용 사례
예전 회사 후임에게 추천했더니, 인터넷 방송 송출 중에 이 프로그램 덕분에 빠르게 대처할 수 있었다는 연락을 받았습니다.
작동 방식

어떻게 작동하나요

핵심 기능

6가지

1서버 상태 3단계 표시

플랫폼 서버의 응답 속도를 계속 재서 정상(초록)·지연(노랑)·장애(빨강)로 보여 줍니다.

2장애가 나면 바로 알림

서버가 느려지거나 끊기면 윈도우 알림으로 즉시 알려 줍니다.

3방송 시작 알림

등록한 스트리머가 방송을 켜면 30초 안에 알림이 오고, 프로필이 플랫폼 색으로 켜집니다.

4항상 화면 맨 위

작업 중에도 가려지지 않는 작은 창이고, 원하는 곳으로 끌어서 옮길 수 있습니다.

5채널 주소만 붙여넣기

채널 주소를 붙여넣으면 어느 플랫폼인지 알아서 판단해 등록합니다.

6휴대폰용 웹판

홈 화면에 추가하면 앱처럼 쓰고, 모니터링 중에는 화면이 꺼지지 않으며 소리·진동으로 알립니다.
