## 알아 두세요

- 일부 사이트는 무료 서버(Render)라 한동안 쓰지 않으면 처음 열 때 30초~1분 걸려요. 포트폴리오를 열면 프롬마루·스토리 담 이음·홈터 서버를 미리 깨워 둡니다.
- "설치 파일 ↓"는 윈도우용 설치 파일(또는 압축 파일)을 바로 내려받아요.
- PRESS-CMS는 사내용 프로그램이라 로그인이 필요해요.
- 경성야록은 소리를 켜고 보시는 걸 권해요.

## 연락 폼 설정 (디스코드로 받기)

1. 디스코드에서 알림 받을 채널 설정 → 연동 → 웹후크 → 새 웹후크 → **웹후크 URL 복사**
2. `assets/config.js` 의 `webhook: ""` 따옴표 안에 붙여 넣고 저장해서 다시 올리기
3. 비워 두면 폼은 이메일 앱을 여는 방식으로 대신 동작해요.

> 웹훅 주소는 공개 사이트에 그대로 보이기 때문에, 스팸이 오면 디스코드에서 그 웹후크를 지우고 새로 만들면 돼요.

## 공유 미리보기 이미지

카카오톡·메신저에 주소를 보내면 `assets/img/og.png`(첫 화면), `assets/img/og/og-프로젝트이름.png`(상세 페이지)가 뜹니다. 카카오톡은 한 번 본 미리보기를 기억하니, 바꾼 뒤에는 [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 주소를 넣고 "캐시 초기화"를 눌러 주세요.
